# 已知问题：当前快照尚未修复


| 问题 | 当前证据与影响 | 建议 |
|---|---|---|
| 标题规则互相冲突 | 同时要求八个不同事件和“第 2 个沿用同一新闻点”；8 月 21 日确实再次出现重复标题 | 删除过时规则，以事件 ID 检查候选去重 |
| 字体规则与脚本不同步 | Skill 要求宋体等价字体及四槽位；脚本仍固定 Songti SC/Times New Roman，未设置 `cs` | 参数化字体，生成前检测，统一样式与 run 设置 |
| 两种日期含义被混用 | 不明事件日期默认填发布日期，能通过区间检查但不等于事件当天发生 | 增加独立日期证据/置信状态；事实不明不得冒写确切发生日 |
| 校验只查输入形式 | 不查网页可达性、日期来源真实性、重复 URL 或重复事件 | 独立信源审计记录与重复检测；代码校验和事实核验分开 |
| 自然周口径不统一 | Skill 写自然周，脚本默认上一完整周；历史“周一至周一”含首尾共八天 | 运行时明确 start/end；相邻期共享边界日时查重 |
| 参数缺失可能被忽略 | 脚本仅在 `--start` 与 `--end` 同时提供时才采用，否则回退默认周 | 缺一项直接报错，避免悄悄改变任务范围 |
| 标题与正文识别脆弱 | Word 脚本根据行尾“。”或“]”等判断正文，问号/感叹号结尾可能误判标题 | 引入显式文档结构或更可靠的解析器 |
| 字数口径未定义 | “8000–11000 中文字符”与历史输出并非统一统计 | 确定正文范围、汉字或字符算法，并随稿输出统计 |
| 规则主要靠 Agent 自检 | 清稿、引用一致性、标题去重等尚无完整自动验收脚本 | 把已有返工案例变成可重复执行的检查 |
| 发布与调度尚未形成可核验实现 | 未见当前包内联网 runner、调度、重试、运行清单或发布连接 | 先稳定单次运行，再扩展到定时任务和人工批准发布 |


本文件描述源快照的实际限制，不表示这些问题已经解决。任何标题增强都必须保留来源归因、拟议/已完成和研究验证范围等事实边界。
